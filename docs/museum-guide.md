# Base Ecosystem Museum — Guide

Welcome to the Base Ecosystem Museum. This guide covers the technology, culture, and builders that define Base — plus how to navigate the exhibitions on the main floor.

## About the museum

Heyrune presents Base as a living technological movement — not a single product, but an ecosystem of protocols, builders, culture, and intelligence unfolding onchain. Scroll the main exhibition to move through time, from early milestones to the AI frontier.

## AI agents on Base

Base is becoming an agent-native chain. Protocols like Virtuals, Avantis, and Bankr deploy autonomous or semi-autonomous agents that trade, coordinate, and interact onchain. The museum's Heyrune Agent is part of this wave — a conversational guide trained on museum knowledge.

## Smart wallet UX

EIP-7702 (Pectra, May 2025) lets a regular EOA temporarily delegate to smart-contract code — batch transactions, pay gas in USDC, and authenticate with passkeys. Coinbase Smart Wallet and paymasters extend this into onboarding without seed phrases.

| Classic EOA | Smart EOA · 7702 |
|-------------|------------------|
| One action per signature | Batch multiple calls |
| Gas paid in ETH only | Gas in USDC or sponsored |
| Seed phrase onboarding | Passkey / biometric login |

## DeFi ecosystem

Base DeFi is where liquidity, lending, and trading concentrate for the Superchain:

- **Morpho** — Lending (#2 globally by TVL)
- **Aerodrome** — Top-3 EVM DEX by volume
- **USDC** — Natively issued on Base by Circle
- **Uniswap** — Deep liquidity hub for new launches

## Under the hood

Base is evolving its stack: migration from OP Stack components toward a proprietary sequencer built on Reth, fault proofs for decentralized verification, and Flashblocks that fix transaction ordering to reduce toxic MEV.
