# Heyrune · Overview

Heyrune is the official web platform for the **Base Ecosystem Museum** — an interactive exhibition at [heyrune.org](https://heyrune.org).

## Product

The museum presents Base as a living ecosystem: milestones, protocols, builders, and culture. Visitors explore scroll-driven exhibitions, protocol references, and a builders index.

**Heyrune Agent** is the platform's native conversational guide. It answers questions about Base, the museum, and ecosystem history using a curated knowledge base maintained by the Heyrune team.

## Exhibition structure

- **Timeline** — seven milestones from Base announcement to the AI frontier
- **Protocols** — DeFi, infrastructure, and consumer apps on Base
- **Builders** — curated index with outbound links
- **Documentation** — technology reference and navigation guide at `/docs`

## Ecosystem focus areas

- Smart wallet UX and account abstraction
- DeFi liquidity and lending (Morpho, Aerodrome, Uniswap, USDC)
- Onchain culture and builder community
- Agent-native applications on Base
